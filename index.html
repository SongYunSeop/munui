seedcover

Deterministic pixel-mosaic cover images from text. The same text always gives the same cover, so every post without a photo still gets a stable, distinct thumbnail.

npm install seedcover
Text

The page must allow cross-origin requests. The extracted text can differ from what the site hashes, so the cover may not match the site's own.

Your text in every theme. Click one to use it: { ...defaultStyle, ...themes.warm }

Examples

Three blog posts, four patterns each: the same title gives a different cover with different options. Seed and salt follow your settings above; nothing is random between renders.

Usage

Cover (any runtime)

import { createCover, coverToSvg } from 'seedcover';

const cover = await createCover(`${title}\n${body}`);
const svg = coverToSvg(cover);
// Put the title on top yourself:
// color: cover.ink

Open Graph PNG (Node + sharp)

import { createOgImage } from 'seedcover/og';

const png = await createOgImage({
  title, cover,
  fontfile: './fonts/NotoSansKR.ttf',
  font: 'Noto Sans KR',
  fontSize: 96, // optional
});
